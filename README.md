# NexusOps Smart Bridge

NexusOps is a working Laravel-to-n8n orchestration project for automated lead enrichment. Laravel acts as the control plane: it accepts and validates leads, records every automation run, triggers an n8n webhook with a callback contract, verifies the callback secret, updates the lead score, and keeps an auditable run history.

## Architecture

```text
Client / CRM
    │ POST /api/v1/leads
    ▼
Laravel Control Plane
    ├── stores Lead + AutomationRun
    ├── POSTs a signed job payload to n8n
    └── exposes a signed callback endpoint
            │
            ▼
n8n: enterprise_lead_enrichment
    ├── Webhook Trigger
    ├── Code node: business-email/company/website scoring
    ├── HTTP Request: callback to Laravel
    └── Respond to Webhook: execution acknowledgement
            │
            ▼
Laravel callback transaction
    └── updates lead status, score, enrichment, execution id, and timestamps
```

## Working functionality

| Area | Implemented capability |
|---|---|
| Lead intake | Validated name, email, company, and website fields |
| Orchestration | Laravel creates an automation run and calls the configured n8n webhook with an idempotency key |
| Enrichment | Importable n8n Code node calculates a score and qualification from business rules |
| Callback security | `X-NexusOps-Secret` is checked with constant-time comparison |
| Observability | Run status, execution id, input/output, error message, and lifecycle timestamps are stored |
| Reliability | Laravel HTTP client retries transient n8n errors; callback updates are transactional and idempotent |
| Operations | Lead search, status filtering, run inspection, and retry endpoint |

## Run the Laravel control plane

```bash
cd backend
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve --host=0.0.0.0 --port=8000
```

The seeded operator account is `operator@nexusops.test` with password `password`.

Configure these values in `.env` before connecting a real n8n instance:

```dotenv
N8N_LEAD_ENRICHMENT_WEBHOOK_URL=http://localhost:5678/webhook/nexus/lead-enrichment
N8N_CALLBACK_SECRET=replace-with-a-long-random-secret
N8N_HTTP_TIMEOUT=10
```

## Import and configure n8n

1. Open n8n and import `workflows/enterprise_lead_enrichment.json`.
2. Activate the workflow. Its production webhook path is `nexus/lead-enrichment`.
3. Set the Laravel callback base URL in the payload environment or keep the URL generated by Laravel when both services share a host.
4. Keep the `X-NexusOps-Secret` value identical to `N8N_CALLBACK_SECRET`.
5. Use the following Laravel endpoint to create a lead after logging in:

```bash
curl -X POST http://127.0.0.1:8000/api/v1/leads \
  -H 'Accept: application/json' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{"name":"Ada Lovelace","email":"ada@analytical.test","company":"Analytical Engines","website":"https://analytical.test"}'
```

The response is `202 Accepted` and includes both the stored lead and its `automation_run`. When the workflow calls back, the lead becomes `enriched` and the run becomes `completed`.

## API surface

| Method | Endpoint | Purpose |
|---|---|---|
| `POST` | `/api/v1/auth/register` | Create an operator |
| `POST` | `/api/v1/auth/login` | Issue a Sanctum token |
| `GET` | `/api/v1/leads` | List and filter leads |
| `POST` | `/api/v1/leads` | Store a lead and trigger n8n |
| `GET` | `/api/v1/leads/{id}` | Inspect a lead and all runs |
| `POST` | `/api/v1/leads/{id}/retry` | Start a new enrichment run |
| `POST` | `/api/v1/n8n/callbacks/lead-enrichment` | Secure n8n callback |
